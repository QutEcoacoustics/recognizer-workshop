🚀 Getting Started

Welcome to the Recognizer Workshop — a tool for training acoustic recognizers using Perch embeddings and recordings hosted on Ecosounds.

📋 Workflow overview

  1. Config — Set up your project file, API token, and folder paths, then start the engine.
  2. Database — Select and load a pre-built Perch embedding database for your site.
  3. Labelled examples — Pull confirmed annotations from the Workbench into the database.
  4. Search — Find more candidate examples using similarity search (query by example or by classifier).
  5. Train — Train a linear classifier on your labelled embeddings.
  6. Refine — Review classifier predictions and add corrections, then re-train.
  7. Inference — Run the trained classifier across the full database and upload results.
These steps appear as tabs you can find at the top of this page

🗂️ Step 1 — Configure your project

  1. Paste your Workbench API token into the token field on the Config tab. You can find your token on your profile page — for Ecosounds: ecosounds.org/my_account
  2. Enter your name
  3. Enter the name of the species you are searching for
  4. Save the configuration

🗄️ Step 2 — Load a database

On the Database tab, build a database of perch-embeddings, downloaded from ecosounds (.sqlite + .usearch files).

If you are doing this workflow as part of a conference workshop, this step will probably be already done for you

🏷️ Step 3 — Fetch labelled examples

Go to Labelled examples and click Fetch labels. This pulls confirmed annotations (events tagged on the Workbench) into the database so they can be used for training.

If your project doesn't have any yet, no worries, you can also manually label examples found via Search.

🔍 Step 4 — Search for more examples

On the Search tab, select a short audio clip containing your target sound. The app embeds it and finds the most acoustically similar clips in the database. Check the results and label anything that contains your target call as positive, and other sounds as negative.

🧠 Step 5 — Train and refine your recognizer

Once you have at least some positive examples, go to the Train tab. Enter a name for your recognizer and click Train recognizer.

Refine: hop over to the Refine tab, run the recognizer over unlabelled examples, label those results.

Iterate: go back to the Train tab, update your recognizer, and repeat the refine process. Adding useful labeled examples improves the recognizer with each iteration

📤 Step 6 — Run inference and upload

When you're happy with the recognizer, go to the Inference tab to score all embeddings in the database. Results can be uploaded back to the Ecosounds to be verified in the rapid verification interface.

Download the recognizer to run it over Ecosounds audio that is not part of your recognizer-workshop database. Contact the Ecosounds team to arrange this.

💡 Tips

  • The Help button (?) on each tab opens contextual guidance for that specific page.
  • The Status tab shows a full snapshot of the engine, database, and label counts at any time.
  • If something goes wrong, check the Logs tab for detailed error messages.
